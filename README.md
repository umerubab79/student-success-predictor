# Student Success Predictor

## Project Overview
This project predicts student performance based on factors such as parental education, study habits, and test scores. It uses Python, pandas, and machine learning models (ANN) for analysis.

## Features
- Data preprocessing and cleaning
- Exploratory data analysis (EDA)
- Visualization of student performance
- Machine Learning model (ANN) for prediction
- Easy-to-use scripts and notebooks
