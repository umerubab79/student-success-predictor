cd /c/Users/umeru/result_Analysis

Explanation
- C: drive → written as /c/
- Backslashes \ → replaced with forward slashes /
- So C:\Users\umeru\result_Analysis becomes /c/Users/umeru/result_Analysis


- To check your current path:
pwd
- To list files in the directory:
ls


👉 Once you run that cd command, your Git Bash terminal will be set to the result_Analysis folder.
